StoreRi7a — Cloudflare Pages
==============================
الملفات:
- index.html : الصفحة الرئيسية
- style.css  : التصميم
- app.js     : السلة والبحث وواتساب
- config.js  : معلومات المتجر والمنتجات

تغيير رقم واتساب:
افتح config.js وغيّر:
whatsapp: "212600000000"
إلى رقمك بصيغة دولية بدون علامة +.

تغيير أو إضافة المنتجات:
عدّل قائمة PRODUCTS داخل config.js.

يمكن رفع الملفات مباشرة إلى Cloudflare Pages.
